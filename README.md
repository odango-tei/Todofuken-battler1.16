# 都道府県＆市区町村バトラー GitHub Pages版

このフォルダの15ファイルが公開用の全ファイルです。配布用ZIPも用意しています。GitHubで公開するときはZIPを展開し、中身をアップロードしてください。全228,037種類・町丁207,454種類・追加の島2,926種類、育成・図鑑・ガチャ7種類・CPU対戦・都市リーグ・天下統一・キャラデザを収録。別途設定を行う都道府県対抗オンライン（Supabase連携）に対応しました。

## Ver1.16 追加更新 — 対戦ページと投擲物の区別

- 「対戦」を押すと、専用の対戦ページが別画面で開くようにしました。オンライン・CPU対戦・都市リーグ・天下統一チャレンジ・強化アイテムを、バトル画面風のデザインで選べます。画面の切り替えにはスライドとフェードのアニメーションを付け、端末の「視差効果を減らす」設定が有効なときは動かしません。
- オンラインを「シンプルバトル」と「都道府県対応オンライン」に分けました。シンプルバトルはログインも県の登録も不要で、自分の編成のまま3対3の自動戦闘をすぐに始められます。都道府県対応は陣営・編成と合言葉で対戦します。一人称フリーバトルは削除し、通常の対戦だけにしました。
- 対戦中に飛ぶ投擲物へ、投げた側の目印を付けました。自分の投擲は青い光と二重リング（照準型）、敵の投擲は赤い光と12本のトゲを持つ輪で、色と形の両方で見分けられます。地形そのものの形・軌道・当たり判定・ダメージは変えていません。
- 対戦画面の左下に「自分（青）／敵（赤）」の小さな目印を表示します。CPU対戦・都市リーグ・天下統一・オンラインのいずれでも同じです。
- 地形データの読み込みを修正しました。公開用の地形ページ（406ページ）をゲーム本体の登録へ戻し、対戦開始時に「地形を読み込めませんでした」と出ていた問題を解消しています。収録数・セーブ形式・ガチャ確率は変更していません。

## Ver1.15 追加更新 — 合言葉で対戦

- オンラインに「合言葉で対戦」を追加しました。オンライン画面の「模擬戦」の隣にある「合言葉で対戦」から、2〜16文字の合言葉を入力します。日本語・英数字・「_」「-」が使えます。
- 同じ合言葉を入力した、別の都道府県の相手と直接対戦できます。先に入力した人が待機し、後から同じ合言葉を入力した人が参加した時点で対戦が始まります。必殺のタイミングと戦術の操作、3対3・6体同時の自動戦闘は従来と同じです。
- 待機は20分で自動的に取り消され、画面の「待機を取り消す」からもやめられます。同じ県同士では対戦しません。同じ相手とは1時間に3戦まで、県レートの増減は通常の対戦と同じです。
- 合言葉は接続先（Supabaseのプロジェクト）ごとに共有されます。合言葉を知っている人だけが入れるので、対戦したい相手と事前に決めて使います。
- 自動で相手を探す「他県の対戦相手を探す」はこれまでどおり使えます。模擬戦・操作確認もそのままです。
- この機能にはオンライン用SQLの追加が必要です。「接続設定」→「SQLを表示・コピー」のSQLを一度実行してください。すでに実行済みの場合は、SQLの末尾にある「合言葉で対戦するための追加分」のブロックだけを実行しても同じ結果になります。既存のテーブル・保存データ・県レートには影響しません。

## Ver1.15 追加更新 — 模擬戦とデータの整理

- オンラインに「模擬戦」を追加しました。ログインも通信も行わず、都道府県対抗と同じ3対3・6体同時の自動戦闘を試せます。オンライン画面の「操作確認」の隣にある「模擬戦」ボタンから開きます。
- 自分の陣営と相手の陣営を47都道府県から選びます。初期値は、所持キャラが一番多い県と、それ以外の県です。
- 編成は本番と同じ条件です。選んだ県の市区町村・町丁・過去自治体と、全陣営共通の未所属から自動で3体を選びます。相手のレベルは自分の平均レベルに合わせます。
- 模擬戦の結果は、県レート・対戦履歴・ランキングに反映されません。描画と操作は通常のオンライン戦と同じです。
- 収録データを見直し、配布物の合計を約38.8MBから約27.7MBへ削減しました。初回に読み込むのは `game.bin` 約9.48MBで、地図は閲覧時に必要な分だけ取り込みます。
  - 過去の境界図（14,800件）は、座標を小数第4位まで丸めたうえで、形を保ったまま頂点を間引きました。面積・参考点・存続期間は元のままです。
  - 町丁の形（207,454件）は、256段階のグリッドで表せる範囲で頂点を間引きました。
  - 東京23区・大阪の歩行マップ、収録数、能力、ガチャ確率、セーブ形式は変更していません。

## Ver1.13 追加更新 — 都道府県対抗オンライン（Supabase連携）

- 対戦メニューに「都道府県対抗オンライン」を追加しました。旧「市区町村奪い合い」は廃止し、通常モードの保存データには影響しません。
- 3対3・6体同時の自動戦闘です。移動と通常投擲は自動、必殺の発動のみ手動です。戦術（分散攻撃・集中攻撃・守備重視）と集中目標を事前に設定します。
- 編成は通常モードの所持・育成を反映します。所属県の現在の市区町村・町丁・過去自治体と、全陣営共通の未所属から3体を選びます。他県のキャラは使用できません。個別の固有色を使い、敵だけを赤くする処理は行いません。
- アカウントはSupabaseのメールアドレスとパスワードです。表示名と所属県を登録し、同じ接続先にいる別の県の相手とマッチングします。同じ県同士では対戦しません。同じ相手とは1時間に3戦までで、対戦参加後24時間は所属県を変更できません。
- 県ごとのレートは初期値1000で、1戦ごとに相手県とのレート差から増減します。47都道府県のランキングと直近10戦を表示します。
- 描画の軽量モードを用意しました。接続設定の「3D描画を使わない」をONにすると、対戦中の3D描画を行わずHPと必殺ボタンだけで対戦を確認できます。
- 操作確認は、ログインなしで通常編成3体による練習を実行します。オンラインの参加者や県レートには影響しません。

### 接続と初期設定

- 配布物には利用者のSupabaseプロジェクトのProject URLとPublishable keyを初期値として収録しています。秘密キー・service_roleキー・データベースパスワードは含みません。接続情報はブラウザのローカル保存で、接続設定画面から変更できます。
- サーバー側のテーブルと関数は、SupabaseのSQL Editorで専用SQLを1回実行して作成します。SQLはゲーム内の「接続設定」→「SQLを表示・コピー」で表示・コピー・保存できます。既存ゲームのテーブルや保存データには触れません。
- 常駐のゲームサーバーではありません。100msごとの進行をサーバー側で計算し、クライアントはその結果を追いかけて描画します。約600msごとに状態を取得し、最長120秒で残りHP割合により決着します。25秒以上通信が途絶えた場合は切断扱いです。
- SupabaseのFreeプランは1週間使わないと休止し、性能を保証するものではありません。小規模なテスト利用を想定しています。

### レート反映と不正対策

- 初期設定では、管理者が編成を確認・承認した利用者同士の対戦だけが県レートに反映されます。未承認でも練習対戦として参加できます。承認はSQLで行います（専用SQLの末尾に手順を記載）。
- 端末内のセーブは改造を検証できないため、申告された育成値をそのまま信用する設定にはしていません。テスト運用として全対戦を反映させる場合も、専用SQLのコメントに手順を記載しています。
- 通常モードの所持・育成・コインは、オンライン対戦で増減しません。

## Ver1.13 追加更新 — 画面の重なり対策・100勝で解放

### 画面比への対応

緊急救助・全画面などの共通操作を、各画面のヘッダー内へ配置する方式に変更しました。小さい画面ではヘッダーの操作を折り返し、内容領域と操作ボタンが重ならないようにします。育成画面のキャラデザと全画面操作も維持しています。

- 編成・育成・図鑑・証の間・交換所・称号・N/R選択・アイテム・海外・投げ方・施設などの共通ヘッダーを調整。交換所・称号にも専用の戻る操作を配置しました。
- 地図のプレイヤー表示、難易度、現在地、保護表示、通知、寄り道ボタン、下部操作の位置を整理。通知を内容に重ねず、表示の高さに応じて配置を更新します。
- ガチャは上部操作と選択・抽選領域を分離。横長の小さい画面ではカテゴリを4列へ変更し、収まりきらない内容はスクロールできます。演出中に抽選ボタンを隠す従来動作は維持しています。
- 通常戦と一人称戦のHP情報を左右に分け、メッセージ・通知・移動スティック・投擲ボタンの位置を調整しました。攻撃判定、能力、地形、カメラ操作は変更していません。
- 東京・大阪のミニマップ、出典、全画面・キャラデザを別の領域へ配置。鉄道の行き先パネルも表示領域に合わせて高さとスクロールを調整します。
- ダイアログは画面内でスクロールし、共通操作は上部へ配置します。地形の編成・育成・引き継ぎ・ガチャ確率は維持しています。

### 200勝の条件を100勝へ

海外の使者の投げ方は、国・地域ごとに100勝で解放する条件へ変更しました。すでに100勝以上あれば、追加の勝利を要求せず編成対象になります。進捗表示・解放通知・編成の検証・引き継ぎの検証も100勝へそろえています。称号「百戦錬磨」の200勝条件も100勝へ変更しました。

勝利数をリセットしたり半分にしたりする変更ではありません。既存の勝利数・編成・解放済みデータを保ちます。証の銀ランクに必要な「使用200回」は勝利数ではないため変更していません。通常・銅・銀・金・プラチナの使用回数は50・100・200・500・1000回のままです。遊び方PDFの該当する200勝表記も100勝に更新しました。

99勝では未解放、100勝で解放・編成可能になる境界、100勝の編成を含むコードの往復、既存245勝の保持を確認。救助後の再読み込みでも100勝の記録・投げ方の解放・島の育成が保持されることを確認しています。全228,037種類と島2,926体の内部名・IDは変更していません。

## Ver1.13 追加更新 — 証の間を勲章展示室へ

「証の間」の表示を、地形の輪郭を刻んだ金属製の勲章を展示するデザインへ変更しました。リボン、月桂樹、金属の縁、刻印、名札をSVGとCSSで描画します。外部画像・フォント・新しいライブラリーは使用していません。

- 通常・銅・銀・金・プラチナを、それぞれ異なる金属色とリボンで表現。獲得済みを立体的に、未獲得を暗い刻印で表示します。
- 地形名の名札、ランク、レベル、累計使用回数、次のランクへの進捗を表示。まだ対象がないときも、最初の証のための展示を表示します。
- 獲得条件、ランクの使用回数、報酬、能力・効果、所持状態、セーブ形式は変更していません。証の取得や昇格を新たに自動付与する変更ではありません。
- 既存の育成画面から入り、「戻る」で育成へ戻れます。証の間では緊急救助ボタンをヘッダー中央へ配置し、説明との重なりを避けています。

訓練所は最初3枠。1分につき経験値2を獲得し、閉じている時間も反映します。覚醒と既存のレベル上限は維持し、編成したまま預けられます。ユーザーレベルは最大100。戦闘と収穫で経験値を得て、Lv11で4枠、Lv21で5枠になります。ユーザーレベルで戦闘能力は変わりません。

庭は1時間に1つ、最大24個まで地形が実ります。基礎N・Rの地形が実る際はSRが5％、SSRが1％。未所持なら獲得、上位レアならレベルを維持して昇格、それ以外は同レアのかけら1個になります。交換対象の政令指定都市175区は庭から除外しています。

野生の勝利で12％の確率で交換用コインを1枚獲得し、その内訳はA70％・B25％・C5％。都市リーグは勝利ごとにA1枚に加え、Bを20％・Cを5％で獲得します。交換所は日本時間0時と12時にラインナップと購入上限を更新。同じ時間帯は再読み込みでも同じです。区、通常コイン、N・Rランダムチケット、ガチャ1回券、なんでもN選択チケットを販売。更新ごとに0.5％でUのかたまり、0.1％でU選択チケットが入荷します。なんでもN選択は基礎SSRもNで獲得でき、上位レアを所持している場合は降格しません。ガチャ1回券は1回ガチャで優先使用します。既存の称号による全区獲得も維持しています。

渋谷区「スクランブル・クロス」は8方向から地形で交差攻撃。1発のダメージは通常投擲の0.7倍。新宿区「都庁フィーバー」は10秒間、攻撃・防御・速度33％アップ。大田区「飛行機アタック」は大田区の地形が飛行機に乗って貫通突撃します。北海道「北海道はでっかいどう」の投射地形をさらに大型化。奥州市と下呂市の弾も、球体の代わりに実際の地形を使用します。3つの新固有技はSR以上、CPUも同じ技を使用します。

追加データはブラウザ保存・旧方式のセーブコード・大規模セーブコードに対応。旧コードには初期値を補います。時刻は端末時計を利用するため、時計改変やデータ巻き戻しへの完全な対策ではありません。
## 編成

編成は専用の全画面です。上部の1〜3番を選んで仲間を配置し、前へ・後へで順番を変更します。名前・都道府県・SR以上・赤・緑・青・黄・無で検索できます。所持一覧の初期順は編成順です。色は見た目の分類だけで、能力や相性は変わりません。現在は全キャラに色があるため、無は該当なしです。順序は自動保存とセーブコードで維持され、CPU対戦にも反映します。

## 公開

このフォルダの中身をGitHubリポジトリのルートへアップロードし、Settings → Pages → Deploy from a branch → main → / (root) を設定します。別のブランチ名なら実際の名前を選んでください。公開URLで index.html が入口になります。

GAS・対戦サーバー・CDNライブラリー・Git LFSは不要です。初回の約7.4MBと、必要になった町の形を配信元から取得します。file://による直開きには対応しません。

都道府県対抗オンラインを使う場合は、前節の「接続と初期設定」のSQL実行が必要です。接続先の初期値は収録済みですが、プロジェクトを作り直した場合は接続設定画面でProject URLとPublishable keyを入力してください。公開URLのオリジンをSupabase側で制限する設定は必須ではありませんが、Auth設定のSite URLとリダイレクトURLを公開URLに合わせる運用を推奨します。

- 領地戦は攻撃ごとの攻略成功・失敗と現在の領地数を表示し、全ターン終了時には最終勝敗も前面表示します。
- 主画面の描画倍率上限を1倍、超軽量設定では0.75倍に抑え、通常の全国移動画面は描画間隔を約32ms以上にします。戦闘の当たり判定・移動速度・攻撃力・確率・報酬は変更していません。
- 結果画面や確認ダイアログの待機中は、不要な3D更新・描画を停止します。戦闘で使い終わった一時メッシュやマテリアル・粒子を解放し、共有の地形モデルは保持します。
- 全国領地図の集計を一括化し、拡大縮小時はSVGの表示範囲のみを更新します。市区町村や島の収録数は減らしていません。

### 市区町村奪い合い

「対戦」またはメニューの「市区町村奪い合い」から開始します。県内47通りと全国の計48範囲から選べます。20・40・60ターンを選択でき、各ターンは自分またはCPUの1行動です。最初に領地をほぼ半分ずつ配り、最後の領地数で勝敗を判定します。同数は引き分けです。

自分のターンはCPU領地を選んで既存の地形戦闘に挑むか、自分の領地の守備を3段階まで補強できます。隣接制限はありません。CPUは専用の進行ボタンで攻撃または守備補強を行い、CPU攻撃時は攻撃戦力と守備力を比較します。同数なら守備側が勝ちます。開始時の編成を基準にCPUの戦力が決まり、自分の領地の守備力には現在の編成と補強を反映します。

対象は既存データの市区町村・特別区・政令市の区1,896単位です。政令市本体は区と二重計上しません。既存データに合わせた収録であり、現在の自治体数・行政境界を保証するものではありません。町丁、過去自治体、湖、島単体は対象外です。地図は県の輪郭と収録位置の点であり、市区町村の行政界ポリゴンではありません。

領地は通常の所持データとは別です。領地戦自体の参加費・対戦報酬はありません。既存の称号など別条件による処理は従来どおりです。各行動後に保存し、引き継ぎコードにも対戦状況を含めます。攻撃中に閉じた場合は、その攻撃を敗北として明示的に再開します。保存に失敗した場合は領地の更新を取り消して通知します。
